TSP — by profile name

RFC 3161 Timestamp Protocol endpoint. Routed by TSP Profile name. Always returns HTTP 200 with an application/timestamp-reply TimeStampResp; success and rejection are encoded in-band via PKIStatus per RFC 3161.

Request a timestamp token

Accepts a DER-encoded TimeStampReq and returns a DER-encoded TimeStampResp. Error conditions are encoded inside the response as PKIStatus rejection with PKIFailureInfo.

TSP — by signing profile name

RFC 3161 Timestamp Protocol endpoint. Routed by Signing Profile name. The Signing Profile must have TSP activated. Always returns HTTP 200 with an application/timestamp-reply TimeStampResp; success and rejection are encoded in-band via PKIStatus per RFC 3161.

Request a timestamp token

Accepts a DER-encoded TimeStampReq and returns a DER-encoded TimeStampResp. Error conditions are encoded inside the response as PKIStatus rejection with PKIFailureInfo.
