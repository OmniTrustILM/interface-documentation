Update Signing Profile

Request to update an existing Signing Profile. If there are existing Signing Records produced using this Signing Profile, creates a new version of Signing Profile. Otherwise updates the latest version in-place.

Authorizations:
SessionAuthCertificateAuthBearerJWTAuth
path Parameters
uuid
required
string <uuid>

Signing Profile UUID

Request Body schema: application/json
required
name
required
string non-empty

Name of the Signing Profile

description
string

Description of the Signing Profile

required
object or (StaticKeyManagedSigningRequestDto (object) or OneTimeKeyManagedSigningRequestDto (object)) (SigningSchemeRequestInterface)
required
object or object or object (WorkflowRequestInterface)
Array of objects (RequestAttribute)

List of Custom Attributes

object (SigningRecordPolicyRequestDto)

Signing Record policy. When omitted, defaults are used (no signing record).

List Signing Records produced under a Signing Profile

Returns a paginated, filterable list of all Signing Records that were produced using this Signing Profile. Supports the same search and pagination parameters as the top-level Signing Records listing.

Authorizations:
SessionAuthCertificateAuthBearerJWTAuth
path Parameters
uuid
required
string <uuid>

Signing Profile UUID

Request Body schema: application/json
required
Array of objects (SearchFilterRequestDto)

Certificate filter input

itemsPerPage
integer <int32> <= 1000
Default: 10

Number of entries per page

pageNumber
integer <int32>
Default: 1

Page number for the request

object (SearchSortRequestDto)

Ordering of the whole result set. When omitted, the endpoint's own default ordering applies, unchanged from before this field existed.

Array of objects (SearchColumnRequestDto)

Fields to return as columns. When omitted, the response carries the endpoint's full default shape, unchanged from before this field existed. Requesting attribute-sourced fields adds their values to each returned object.
