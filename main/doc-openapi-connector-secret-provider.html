Connector Attributes v2

Attribute-definition registry and stateless callback surface for NG connectors.

Execute an attribute callback

Resolves dynamic attribute content for the attribute identified in the request, using the supplied scope and current attribute values.

Authorizations:
ConnectorAPIKeyAuthCertificateTLSAuthNoAuthBasicAuth
Request Body schema: application/json
required
connectorInterface
required
string (ConnectorInterface)
Enum: "info" "health" "metrics" "attributes" "authority" "discovery" "entity" "compliance" "cryptography" "notification" "secret" "signatureFormatting" "cadesFormatting" "jadesFormatting" "padesFormatting" "xadesFormatting"

Provider interface the triggering schema belongs to. Core-stamped from /v2/info.

interfaceVersion
required
string non-empty

Version of the provider interface. Core-stamped from /v2/info.

attributeUuid
required
string <uuid>

Connector-global UUID of the attribute whose callback fired — the dispatch key.

attributeName
required
string non-empty

Name of the attribute whose callback fired. Informative / logging.

required
Array of objects (ScopedAttributes)

Route scope chain, credentials expanded inline by Core. Empty when the form has no parent scope.

required
Array of objects (RequestAttribute)

The dependsOn-named form values only, reference-typed values expanded inline by Core.

object (PaginationRequestDto)

Optional pagination for content responses.
